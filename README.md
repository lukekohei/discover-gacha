# DISCOVER GACHA PWA — 時間帯一括設定版（v5）

## 今回の変更
- トップのコピーを「ご来展ありがとうございます。／小さなサプライズを。」の2行・中央揃えに変更。
- 「全時間帯共通の在庫」と「時間帯別の排出ルール」を独立した枠・保存ボタンに分離。
- 4時間帯を一画面で編集し、一括保存。開始／終了時刻、区分、A〜E賞の比率、A・B賞の目安個数、運用メモを編集可能。
- パスワード保護、在庫表示、抽選履歴・リセット、全賞ハロウィン動画は継続。

## 初回の設定
ホーム画面のガチャアプリで「スタッフ設定」を開き、パスワードを入力します。未設定なら6文字以上のパスワードを作成します。

1. 「全時間帯共通の在庫」に実際の残数を入力し、「共通在庫を保存」。−1は無制限、0は抽選対象外です。合計には個数管理中の賞のみ含めます。
2. 「時間帯別の排出ルール」の4行を編集します。初回は下記の画像由来の時間割を下書き表示します。

| 時間帯 | 区分 | A賞目安（個） | B賞目安（個） |
|---|---|---:|---:|
| 11:30–12:30 | 抑制 | 1 | 5 |
| 12:30–14:00 | 通常 | 3 | 8 |
| 14:00–16:00 | ピーク | 12 | 30 |
| 16:00–18:00 | 在庫調整 | 4 | 7 |

3. 各行のA〜E比率を入力します。画像には各賞の確率がないため、初回は保存済みの従来「通常」の比率を全行に仮入力します。区分名だけでは当たりやすさは変わりません。
4. 「通常（上記の時間外）」の比率も設定します。
5. 「時刻で自動切替」をONにして「時間帯設定をまとめて保存」。以降は日本時間で自動切替し、手動で設定し直す必要はありません。

各行の比率は合計100なら％相当です。合計100でなくても相対比率として扱います。在庫が0の賞は除外し、残る賞で再計算します。全賞0の比率や、時間帯の重複・逆転・空欄は保存できません。時間帯は開始を含み、終了は含みません（12:30から次の行）。日をまたぐ設定はできません。

目安個数は計画の参考値です。必ずその個数を排出する保証、時間帯別在庫の取り置き、排出上限ではありません。「在庫調整」の行も保存した比率で抽選します。在庫に応じた比率の自動引上げはありません。必要に応じてC賞などの比率を編集・一括保存してください。

自動切替OFFの場合は「自動切替OFFのときに適用する設定」で選んだ行を、一括保存後から使用します。予定した時間以外は通常の比率を使います。

## 既存設定の引継ぎ
初回に表示される4行は下書きです。「時間帯設定をまとめて保存」を押すまでは、以前の時間帯と比率を使います。旧設定を勝手に変更しません。一度保存すると、以降は保存済みの4行が表示されます。在庫・履歴・パスワードは同じURL・同じアプリの保存領域で継続します。

在庫保存と時間帯設定保存は独立しています。時間帯の比率を保存しても在庫は変わりません。在庫を保存しても比率や時刻は変わりません。画面を閉じる・演出確認へ移る前に、それぞれ保存してください。

## 履歴とリセット
スタッフ設定の下部で、抽選合計、賞別当選回数、日時（日本時間）・当選賞・適用時間帯を確認できます。新しい順に50件ずつ表示します。

「履歴をリセット」→確認画面の「履歴を削除する」で履歴だけを削除します。現在在庫、比率、時間帯設定、パスワードは維持します。テストで減った在庫は戻らないため、実際の個数を入力して共通在庫を保存してください。

抽選開始時点で在庫減算と履歴記録を行います。途中でアプリを閉じても消費済みです。「演出の確認」は在庫・履歴に影響しません。

## パスワード
「パスワード変更」で現在と新しいパスワードを入力します。閉じる／別アプリへの切替／2分間無操作で再ロック。パスワードは端末内にソルト付きハッシュとして保存します。これはスタッフ画面の操作ロックで、端末データ自体の暗号化ではありません。パスワードを忘れた場合の解除画面はありません。Webデータ消去では在庫・履歴も消えるため、安易に消さないでください。

## GitHubへの更新
1. ZIPを展開し、中身すべてを既存のリポジトリへ同じ構成で上書きアップロードします。ZIPそのものはアップロードしません。app.jsとschedule.jsを含めてください。
2. GitHub Pagesの公開完了後、iPadをオンラインで起動します。少し待って閉じ、開き直します。
3. 画面下の「オフライン準備完了（時間帯一括設定版）」と新しいコピーを確認します。古い場合は更新取得後にもう一度開き直します。アプリやWebデータの削除は不要です。
4. スタッフ設定で時間帯を保存後、機内モード・Wi-Fi OFFで再起動と動画の再生を確認します。

## 初めての導入
リポジトリのSettings → Pages → Deploy from a branch → main / (root) → Save。公開URLをSafariで開き、オフライン準備完了を待って「共有 → ホーム画面に追加」。ホーム画面のアイコンで開き直して、再度準備完了を確認します。Apple IDやSwift Playgroundは不要です。

通常Safariとホーム画面のアプリは保存領域が異なる場合があります。本番の設定はホーム画面のアプリで行ってください。在庫・履歴は端末内のみで複数iPadは同期しません。初回導入・更新時は通信が必要です。
