# DISCOVER GACHA PWA版

Apple ID・App Store・Swift Playground不要。A〜E賞すべて、確定したA賞と同じハロウィン2D背景・動き・7秒・0.5秒クロスフェードです。賞の文字だけが変わります。

## GitHubへ配置（PCで操作）
1. ZIPを展開します。
2. ガチャ専用リポジトリを用意します。既存のアンケート用リポジトリを使う場合は、アンケートのindex.htmlやsw.jsを上書きしないでください。
3. 「Add file → Upload files」で、展開した中身をフォルダ構造ごとアップロードしてコミットします。ZIPそのものではありません。
4. リポジトリ直下にindex.html、sw.js、offline.js、manifest.webmanifest、各PNG、videosフォルダがある状態にします。videos内にA.mp4〜E.mp4が必要です。
5. 「Settings → Pages → Build and deployment → Source: Deploy from a branch」、Branchはmain、フォルダは/(root)を選んでSaveします。
6. 公開完了後、Pagesに表示されるHTTPSのサイトURLを開きます。例：https://ユーザー名.github.io/リポジトリ名/ 。github.com上のコード画面やRawのURLは使いません。

既存のPagesサイトのサブフォルダに置く場合も動くよう、参照先は相対パスです。その場合はガチャを置いたフォルダのURL（末尾/）を開きます。既存サイトのサービスワーカーがそのフォルダを制御している場合は調整が必要なので、専用リポジトリが簡単です。

## iPadへ保存
1. 通信できる状態で、Safariで公開URLを開きます。
2. 画面下の「動画を端末に保存中…」が「オフライン準備完了」になるまで待ちます。
3. Safariの共有ボタン →「ホーム画面に追加」。表示される場合は「Webアプリとして開く」をONにして追加します。
4. ホーム画面の「ガチャ」アイコンから起動し、ここでも「オフライン準備完了」を確認します。
5. 「スタッフ設定」→A賞の「再生」で確定動画を確認します。この操作は在庫を減らしません。
6. 機内モードにしWi-FiもOFF。アプリを閉じてホーム画面から開き直し、A〜E賞の演出を再生できることを確認します。

初回のみ通信が必要です。ZIPやindex.htmlを「ファイル」アプリから直接開く方法では、PWAのオフライン保存は動きません。Apple IDは不要ですが、会社の端末設定でホーム画面追加やWebデータ保存が許可されている必要があります。

## 操作と仮設定
「ガチャをまわす」→動画→結果→「次の抽選へ」。スタッフ設定で時間帯別比率と残数を編集できます。初期比率は全時間帯A:2/B:8/C:20/D:30/E:40、残数は全て−1（無制限）。0は対象外、正の整数は1ずつ減算。自動切替は初期OFF。ONの場合は日本時間10–12時、12–15時、15–18時、それ以外は通常です。時間帯を切り替える前に保存してください。

当選結果は抽選開始時点で保存・減算します。抽選中に終了した場合も消費済みです。スタッフ設定はパスワードで保護します。初回に6文字以上のパスワードを設定してください。

## 当日の確認
- 通常Safariとホーム画面のアプリは保存領域が異なることがあるため、本番用の設定はホーム画面から起動したアプリで行ってください。
- テスト後に残数を本番値へ戻してください。
- 在庫・履歴は端末内のみ。複数iPadの同期やサーバー送信はありません。
- SafariのWebデータ削除や空き容量不足などでオフラインデータが消える可能性があります。当日も機内モードで起動確認してください。
- 画面固定にはiPadのアクセスガイドを利用できます。

## 今回の更新（全賞ハロウィン版）
ZIPを展開し、中身を既存のGitHubリポジトリへ同じ構成で上書きアップロードしてください。videos/B.mp4〜E.mp4だけでなく、sw.js、offline.js、index.htmlも更新してください。キャッシュの版番号を更新済みです。公開が反映された後、iPadをオンラインにしてアプリを開き、しばらく待ってから閉じて開き直してください。「オフライン準備完了（全賞ハロウィン版）」とスタッフ設定内の「A〜E賞：全賞ハロウィン2D版（各7秒）」を確認し、各賞の「再生」で確認してください。古い表示ならオンラインのままもう一度開き直します。設定や在庫を保持するため、Webデータの削除やアプリ削除は不要です。

## スタッフ設定のパスワード・履歴（v3）
- 更新後の初回に「スタッフ設定」を押すと、パスワード作成画面が出ます。6文字以上を2回入力して設定します。
- 以降はパスワードを入力した場合だけ設定・履歴が開きます。パスワードは端末内にソルト付きハッシュで保存し、平文では保存しません。
- 「閉じる」、別アプリへの切替、2分間無操作でロックします。パスワード変更はスタッフ設定内の「パスワード変更」から、現在と新しいパスワードを入力します。
- パスワードは本番で使うホーム画面のアプリから設定してください。各端末で個別設定です。パスワードは控えてください。パスワードだけを忘れた場合の解除画面はありません。Webデータを消すと在庫・履歴も失うため、安易に消去しないでください。
- これはスタッフ画面の操作ロックです。抽選履歴そのものの暗号化やサーバー認証は行いません。
- スタッフ設定を下にスクロールすると「抽選履歴」があります。全抽選数・各賞の当選回数と、日時（日本時間）・当選した賞・適用した時間帯を表示します。
- 履歴は新しい順に50件ずつ表示。「古い履歴」「新しい履歴」で移動します。演出確認は履歴に含みません。
- 既存の在庫・設定・履歴の保存キーは変更していません。同じURL・同じアプリの保存領域を使えば引き継ぎます。
- 各時間帯の比率を保存し、「時刻で自動切替」をONにして保存すれば、その後の手動切替は不要です。

更新はZIPの中身をGitHubへ上書きします。password.jsとstaff.jsも必ずアップロードしてください。オンラインでアプリを開き、閉じて開き直し、「オフライン準備完了（スタッフ保護版）」を確認します。「全賞ハロウィン版」の表示が残る場合は、更新取得後にもう一度開き直します。

認証と履歴表示のロジックを検証済み。iPad実機の画面・操作は未検証です。
